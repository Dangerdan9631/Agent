# Templates

Toolkit-owned templates copied into projects during init or step instantiation. This layer holds canonical `spec.md`, `plan.md`, and `tasks.md` step output templates plus manifesto authoring templates (`manifesto-global.md`, `manifesto-step.md`).

Step output templates include inline fill instructions enforced by the core instantiation layer. Manifesto templates include `[PLACEHOLDER]` tokens for interview-driven authoring via `/spec-n-manifesto`.
