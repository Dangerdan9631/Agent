# Diagram Models

## Purpose

This directory contains immutable scope-specific graphs ready for JSON, matrix, and HTML artifact writers.

## Conventions

- Diagram scope IDs are stable and use exact package manifest names.
- Nodes and relationships retain semantic graph IDs.

## Contents

- `DiagramGraph.ts` represents one generated diagram scope.
- `ArchitectureGenerationResult.ts` captures validation and artifact generation outcome.
